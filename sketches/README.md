# Sketches

Put the team's hand-drawn sketches here (photos or scans, `.jpg`/`.png`), named so the report links resolve:

`intro.jpg`, `storyboard.jpg`, `q1.jpg` … `q7.jpg` (owners: see `docs/TEAM_TASKS.md`)

Each sketch follows the "Sketch: views and encodings" table for its question in `docs/M2_report.md`. Before scanning, check that each one shows:

- [ ] Title
- [ ] Axis labels **with units** and the scale range (e.g. "Ports per 100,000 residents, 0–1,700, sqrt")
- [ ] Legend, including the **zero / incomplete / not evaluated / missing** entries
- [ ] Which data field drives each visual channel (position, length, area, color, shape)
- [ ] The permanent note or caption, written out
- [ ] Interactions marked in a second color (click, hover, dropdown, slider) with arrows to the views they update
- [ ] Source line: "AFDC snapshot 2026-10-30; ACS 2020–2024"
- [ ] Two or three real values from the sample tables written onto the sketch (e.g. LA County = 18,829 ports), so the sketch is clearly tied to the data
